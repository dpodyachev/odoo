# URL rewriting in Odoo Online: clean URLs without redirects?

Website Odoo Online · answered 2026-11-19

Question: Is it possible in Odoo Online (from Odoo 19) to rewrite URLs to get clean addresses and avoid redirects? If not, is it possible with Odoo Community?

Answer:

There is no .htaccess in Odoo, but there is the menu Website → Configuration → Redirects (model website.rewrite), and it works in Odoo Online.

  • 301 / 302 – a normal redirect from an old address to a new one.
  • 308 Redirect / Rewrite – changes the address of a section itself, e.g. /shop → /boutique. The old address redirects to the new one, and menus and links on the website are generated with the new address automatically. It only works for sections generated by Odoo code (/shop, /blog, etc.).
  • Regular pages: change the address in Page Properties → URL; there is also a “create a redirect” checkbox.

A true rewrite “without any redirect”, as in nginx, is only possible on your own server (Community or Enterprise on-premise). In Odoo Online it can only be done from outside: if the domain is proxied through Cloudflare, Rules → Transform Rules → URL Rewrite can rewrite the path before it reaches Odoo – but Odoo itself keeps generating links with its own addresses.

# Setting up accounting for manufacturing

Manufacturing Accounting · answered 2026-11-19

Question: How do I set up accounting for the production process – materials and finished products? Accounts on product categories and on special locations (production, inventory loss) apparently aren't enough.

Answer:

In short, the path to make manufacturing and accounting fit together:

  • Product categories: enable Automated (perpetual) valuation and set the accounts – stock valuation, input, output.
  • The virtual “Production” location: set its own valuation accounts so that raw material consumption and finished goods go through a work-in-progress (WIP) account.
  • Work centers: enter the cost per hour and add operations to the bills of materials (BoM) – then the product cost includes labour, not just materials.
  • Month end: if a manufacturing order is still open, from Odoo 17 on it can be posted as work in progress via the WIP accounting action.
  • Management accounting: an analytic account per manufacturing order.

# Product Margin report: wrong expected margin for variants

Sales Reporting · answered 2026-11-19

Question: For “Expected Margin” the report uses the template price ($1), not the variant price ($1 + variant extra $267.78). Sales Gap and Expected Margin are therefore wrong. Can this be fixed?

Answer:

It is not a configuration error – the report is built this way. In the source code (product_margin, Odoo 18) the “expected sale” is computed as quantity × list_price of the product template. Variant extra prices (price_extra) are not taken into account – hence 32 × $1.

  • Simple way: keep the real base price on the template instead of $1.
  • Otherwise a small module that replaces the template list_price in this query with the variant price (lst_price).

# Odoo 19 on Odoo.sh: parse carrier emails with AI and update tracking on purchase orders?

Purchase Inventory AI · answered 2026-11-19

Question: We run Odoo 19 Enterprise on Odoo.sh. Which OCA modules for carrier/tracking integration should we look at?

Answer:

Incoming receipts have no ready-made “purchase tracking number” field. It is more practical to write the number into carrier_tracking_ref on the receipt (stock.picking) – that field comes with the delivery module.

  • A separate email alias for carrier emails.
  • An automation rule on incoming emails.
  • An AI call that extracts the order number and the tracking number from the text.
  • Writing them to the receipt plus a message in the purchase order's chatter.

The OCA has ready carrier modules in the delivery-carrier repository, but they are designed mostly for outgoing shipments.

# Cash flow forecasting for an IT consulting firm: hourly billing plus subscriptions

Accounting Services · answered 2026-11-19

Question: 75% of services are billed hourly, 25% as fixed monthly amounts (subscription), Odoo 19. Wanted: a cash flow forecast with planned, recorded, invoiced and paid amounts – each amount only once – tax shown separately, personnel costs from payment planning.

Answer:

A ready base is the OCA module mis_builder_cash_flow (repository account-financial-reporting). It builds a forecast from receivables and payables by due date and lets you add planned lines: salaries, leasing, fixed costs.

  • Subscriptions: by the dates of the next invoices.
  • Timesheets: hours not yet invoiced (the qty_to_invoice field on order lines).
  • Invoices: by due date.

The “each amount only once” rule (plan → timesheet → invoice → payment) has to be added yourself – a small extension.
