🛡️ Cloudflare Access – connexion par code e-mail

✅ Vous êtes connecté via Cloudflare Access. Pas de mot de passe partagé : seules les personnes inscrites dans la règle et qui saisissent le code reçu par e-mail entrent.

Ce qui se passe ici

  1. Cloudflare Access se place devant le site. Avant que Cloudflare Pages ne serve la page, Access vérifie que le visiteur a une session valide.
  2. Sans session, Access redirige vers la page de connexion de l’équipe (…cloudflareaccess.com). On saisit son adresse e-mail et on reçoit un code à usage unique.
  3. La règle « Owner only » autorise une seule adresse. Les autres ne reçoivent même pas de code.
  4. Après la connexion, Access pose un cookie pour 24 heures – on reste connecté pendant ce temps.
  5. Toutes les adresses de cette page sont protégées : 2027.pp.ua, goldberg.pp.ua, www.goldberg.pp.ua et goldberg-odoo.pages.dev. Sinon la page serait ouverte via un miroir.
  6. Il n’y a rien pour cela dans le code du site – ni fonction, ni secret. Tout est réglé dans le tableau de bord Zero Trust.
