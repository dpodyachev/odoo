🛡️ Cloudflare Access – login with an e-mail code

✅ You are signed in via Cloudflare Access. No shared password: only people listed in the policy who enter the code from their mailbox get in.

What happens here

  1. Cloudflare Access sits in front of the website. Before Cloudflare Pages serves the page, Access checks whether the visitor has a valid session.
  2. Without a session, Access redirects to the team login page (…cloudflareaccess.com). You enter your e-mail address and receive a one-time code.
  3. The policy "Owner only" allows exactly one address. Other addresses don't even receive a code.
  4. After login, Access sets a cookie for 24 hours – you stay signed in that long.
  5. All addresses of this page are protected: 2027.pp.ua, goldberg.pp.ua, www.goldberg.pp.ua and goldberg-odoo.pages.dev. Otherwise the page would be open through a mirror.
  6. There is nothing for this in the website code – no function, no secret. Everything is configured in the Zero Trust dashboard.
