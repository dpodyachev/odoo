🛡️ Cloudflare Access – Anmeldung per E-Mail-Code

✅ Sie sind über Cloudflare Access angemeldet. Kein gemeinsames Passwort: Zugang hat nur, wer in der Richtlinie steht und den Code aus seinem Postfach eingibt.

Was hier passiert

  1. Cloudflare Access sitzt vor der Website. Noch bevor Cloudflare Pages die Seite ausliefert, prüft Access, ob der Besucher eine gültige Sitzung hat.
  2. Ohne Sitzung leitet Access zur Anmeldeseite des Teams um (…cloudflareaccess.com). Dort gibt man seine E-Mail-Adresse ein und erhält einen einmaligen Code.
  3. Die Richtlinie „Owner only“ erlaubt genau eine Adresse. Andere Adressen bekommen gar keinen Code.
  4. Nach der Anmeldung setzt Access ein Cookie für 24 Stunden – so lange bleibt man angemeldet.
  5. Geschützt sind alle Adressen dieser Seite: 2027.pp.ua, goldberg.pp.ua, www.goldberg.pp.ua und goldberg-odoo.pages.dev. Sonst wäre die Seite über einen Spiegel offen.
  6. Im Code der Website gibt es dafür nichts – keine Funktion, kein Secret. Alles ist im Zero-Trust-Dashboard eingestellt.
