Логи Odoo: warn чи warning, log_level чи --log-level? Шпаргалка

Конфіг, командний рядок, click-odoo-update – три написання і три види рівнів. Одна таблиця, щоб підглядати, і помилки, за яких Odoo мовчки лишається на INFO.

Сам постійно забуваю: warn чи warning? log_level чи log-level? Відповідь залежить від того, де це пишеш. Усе на одній сторінці (перевірено за кодом Odoo 17).

Просте правило

  • В odoo.conf – підкреслення: log_level, log_handler, log_db_level.
  • У командному рядку – дефіс: --log-level, --log-handler, --log-db-level.
  • log_level приймає власні слова Odoo, малими: warn (не warning!), error, info, debug …
  • log_handler чекає рівні Python ВЕЛИКИМИ: WARNING, ERROR, DEBUG.
  • log_db_level чекає рівні Python малими: warning, error (за замовчуванням warning).

Шпаргалка

Щоodoo.confКомандний рядокclick-odoo-update
Загальний рівеньlog_level = warn--log-level=warn--log-level=warn
Рівень для логераlog_handler = werkzeug:WARNING,odoo.addons.sale:DEBUG--log-handler=odoo.addons.sale:DEBUG (можна кілька разів)через конфіг -c
Файл логуlogfile = /var/log/odoo/odoo.log--logfile=…--logfile=…
Syslogsyslog = True--syslog–
У базу данихlog_db = %d, log_db_level = warning--log-db=%d --log-db-level=warningчерез -c
Скорочення–--log-sql, --log-web–

Допустимі значення

ПараметрЗначення
log_levelinfo (за замовчуванням), warn, error, critical, debug, debug_sql, debug_rpc, debug_rpc_answer, notset, test, runbot
log_handlerPREFIX:РІВЕНЬ, рівень = DEBUG · INFO · WARNING (або WARN) · ERROR · CRITICAL; порожній префікс = кореневий логер, напр. :INFO
log_db_leveldebug · info · warning · error · critical
log_db%d = поточна база або назва окремої бази для логів

Приклади

click-odoo-update (та інші скрипти click-odoo) мають власні ключі --log-level і --logfile з тими самими значеннями, що й Odoo. Налаштування окремих логерів беруться з конфігу, переданого через -c.

Тихі помилки

Командний рядок одразу лається на неправильне значення (invalid choice: 'warning'). Конфіг – ні: Odoo просто працює далі на INFO, а ти дивуєшся, чому лог такий великий:

log_level = warn ставить WARNING лише логерам odoo і werkzeug. Сторонні бібліотеки й далі пишуть INFO через кореневий логер. Для зовсім тихого логу додайте log_handler = :WARNING.
