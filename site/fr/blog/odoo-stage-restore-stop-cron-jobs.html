Restaurer une sauvegarde en préproduction – sans que les crons et les queue jobs ne se déclenchent

Pourquoi une préproduction peut envoyer des relances à de vrais clients, et l’ordre des étapes qui l’évite : SQL avant le premier démarrage, neutralize, configuration dédiée.

La base de production est restaurée en préproduction pour tester une mise à jour. Odoo démarre – et exécute aussitôt tout ce qui est devenu « échu » pendant l’arrêt : relances et factures par e-mail, synchronisation avec la boutique, la banque ou les transporteurs, tâches en file d’attente. Avec de vraies données clients et de vrais identifiants. L’accident classique de préproduction.

Le point essentiel : Odoo lance ses threads cron et le job runner dès le démarrage. Désactiver dans l’interface, c’est trop tard. Tout doit être fait avant qu’Odoo ne voie la base pour la première fois.

1. Restaurer – Odoo reste arrêté

2. Neutraliser en SQL

Les tables queue_job et fetchmail_server n’existent que si les modules sont installés – supprimez sinon ces lignes. La liste zz_stage_cron_before aide à réactiver plus tard, volontairement, certains crons en préproduction.

Depuis Odoo 16, il existe aussi la commande intégrée neutralize : elle désactive notamment les actions planifiées, les serveurs de messagerie et les fournisseurs de paiement, et affiche un bandeau « neutralisé ». Je l’utilise comme base et j’ajoute le SQL pour les modules tiers comme queue_job.

3. Une configuration de préproduction comme deuxième filet

Même si une base est restaurée sans neutralisation, rien ne peut sortir du serveur avec cette configuration : pas de thread cron, pas de job runner, e-mails uniquement dans le mail catcher.

4. Vérifier

  • Ne livrer la préproduction aux tests que lorsque les trois requêtes donnent le bon résultat.
  • Remplacer en préproduction les identifiants des services externes (boutique, banque, transport, paiement) par des clés sandbox, ou les supprimer.
  • Garder toute la procédure dans un script – une préproduction fraîche prend alors quelques minutes, et aucune étape n’est oubliée.
