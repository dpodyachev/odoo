E-mail in Odoo: why the mailbox password is not enough – 2-step verification, app passwords, OAuth

Cet article n’est pas encore disponible en français – voici la version anglaise.

You enter the Gmail or Outlook password in Odoo and get "Username and Password not accepted". Google and Microsoft no longer let programs in with the normal password. Step by step: turn on 2-step verification, create an app password, set up outgoing and incoming mail in Odoo so that e-mails become leads, what to do with Outlook / Microsoft 365, and what each error message means.

The first thing almost everyone does after installing Odoo: connect the company mailbox. Enter server, address, password – and Odoo answers with an authentication error, although the password is correct. That is not an Odoo bug. Google and Microsoft have switched off logins with the normal account password for mail programs. Odoo, Thunderbird or a scanner that sends PDFs need either an app password (a separate 16-letter password, available only with 2-step verification) or a login via OAuth (the "Gmail" / "Outlook" button in Odoo).

What we checked: the field names and values below against Odoo 18 Community in our test database. The message "The setting you are looking for is not available for your account" we got ourselves when creating an app password – 2-step verification was off. The live send-and-receive test with a real Gmail mailbox is still pending; we will add the result here.

Step 1: turn on 2-step verification (Google)

  1. Open myaccount.google.com/signinoptions/twosv and sign in.
  2. Click Turn on 2-Step Verification.
  3. Add a second step: phone number (SMS / call) or the Google Authenticator app. Passkeys alone are not enough for app passwords – add a phone or Authenticator as well.
  4. Confirm. From now on, new devices ask for the second step – Odoo will not, because it uses the app password.

Step 2: create an app password

  1. Open myaccount.google.com/apppasswords (the page is not in the menu – use the link or search "App passwords" in the account settings).
  2. Enter a name, e.g. Odoo, and click Create.
  3. Google shows 16 letters in four groups (abcd efgh ijkl mnop). Copy them now – Google does not show them again. Spaces do not matter; we enter them without spaces.
  4. One app password per program: Odoo, scanner, Thunderbird – each its own. Then one can be revoked without breaking the others.

If Google answers "The setting you are looking for is not available for your account" instead of the form, the reason is one of these:

  • 2-step verification is off – the most common case. Do step 1.
  • 2-step verification is on, but the only second step is a passkey or security key – add phone or Authenticator.
  • The account is enrolled in Advanced Protection – app passwords are impossible, use OAuth.
  • Google Workspace: the admin has disabled app passwords or less secure access – use OAuth or ask the admin.
  • Important: changing the Google password revokes all app passwords. Change the main password first, then create the app password.

Step 4: outgoing mail in Odoo

  1. Settings ‣ General Settings ‣ section Emails ‣ tick Use Custom Email Servers ‣ Save.
  2. Settings ‣ Technical ‣ Outgoing Mail Servers ‣ New (or the link under the checkbox).
  3. Server: smtp.gmail.com, port 587, connection encryption TLS (STARTTLS) (or 465 with SSL/TLS).
  4. Authenticate with: Username. Username: the full address. Password: the 16 letters.
  5. FROM Filtering: the mailbox address. Gmail sends only as the logged-in address (or aliases configured under "Send mail as") – without the filter, mails from other senders get rewritten or rejected.
  6. Test Connection, then send yourself a quote from Sales to see the mail arrive.

Step 5: incoming mail – e-mails become leads

  1. Settings ‣ Technical ‣ Incoming Mail Servers ‣ New (the menu appears in developer mode).
  2. Server type IMAP Server, server imap.gmail.com, port 993, SSL/TLS ticked, username and app password as above.
  3. Under Actions to Perform on Incoming Mails ‣ Create a New Record: Lead/Opportunity. Every new e-mail that is not an answer to an Odoo mail becomes a lead; replies land in the thread of their document.
  4. Test & Confirm. Odoo fetches every 5 minutes; to start immediately: Fetch Now.
  5. Use a mailbox that exists for this purpose (info@, anfrage@) – not a personal mailbox, otherwise every newsletter becomes a lead.
  6. Gmail IMAP no longer needs to be enabled in the Gmail settings – Google removed the switch in 2025; older guides still mention it.

Outlook and Microsoft 365: only OAuth

Microsoft does not offer an easy way with a password: Outlook.com accounts accept only OAuth since September 2024, and Microsoft 365 has switched off password logins for IMAP and is retiring them for SMTP during 2026. Odoo Community has the module for it (microsoft_outlook) – the steps are in our article on Outlook, Gmail and WhatsApp. In short:

  • register an app in Microsoft Entra ID (portal.azure.com ‣ App registrations) – free;
  • Odoo must be reachable via https at a fixed address, because Microsoft sends you back to https://<your-odoo>/microsoft_outlook/confirm – freeze web.base.url;
  • in the outgoing and incoming server choose Outlook OAuth Authentication and click Connect your Outlook account – the mailbox owner signs in once;
  • the client secret in Azure expires (6–24 months) – put a reminder in the calendar, otherwise mail stops silently.
  • Gmail / Google Workspace can use the same way (google_gmail, Google Cloud OAuth client) – the cleaner solution for Workspace.

Security

  • An app password gives full access to the mailbox – reading and sending – and bypasses 2-step verification. Treat it like the main password.
  • Odoo stores it in the database; it is in every backup. Backups therefore belong encrypted and not on the same server only.
  • Do not keep the main Google or Microsoft password in files on the server – Odoo does not need it.
  • Name app passwords after the program; remove those no longer used in the Google account (same page).
  • Gmail limits sending to about 500 recipients per day (Workspace about 2,000). For newsletters use a mailing service, not the mailbox.

Conclusion

With Gmail the way is: 2-step verification on, app password created, login tested from the server, outgoing and incoming server in Odoo – half an hour. With Outlook and Microsoft 365 there is no way around OAuth; it takes an app registration and Odoo with https at a fixed address.
