# Réécriture d'URL avec Odoo Online : des URL propres sans redirection ?

Website Odoo Online · répondu le 19.11.2026

Question: Est-il possible dans Odoo Online (à partir d'Odoo 19) de réécrire les URL pour avoir des adresses propres et éviter les redirections ? Sinon, est-ce possible avec Odoo Community ?

Réponse:

Il n'y a pas de .htaccess dans Odoo, mais il y a le menu Site Web → Configuration → Redirections (modèle website.rewrite), et il fonctionne dans Odoo Online.

  • 301 / 302 – une redirection classique d'une ancienne adresse vers une nouvelle.
  • 308 Redirect / Rewrite – change l'adresse de la rubrique elle-même, par exemple /shop → /boutique. L'ancienne adresse redirige vers la nouvelle, et les menus et liens du site sont générés automatiquement avec la nouvelle adresse. Cela ne fonctionne que pour les rubriques générées par le code d'Odoo (/shop, /blog, etc.).
  • Pages ordinaires : changez l'adresse dans Propriétés de la page → URL ; il y a aussi la case « créer une redirection ».

Une vraie réécriture « sans aucune redirection », comme dans nginx, n'est possible que sur votre propre serveur (Community ou Enterprise on-premise). Dans Odoo Online, seulement depuis l'extérieur : si le domaine passe par Cloudflare (proxy), Rules → Transform Rules → URL Rewrite peut réécrire le chemin avant Odoo – mais Odoo continue de générer ses liens avec ses propres adresses.

# Configurer la comptabilité pour la fabrication

Manufacturing Accounting · répondu le 19.11.2026

Question: Comment configurer la comptabilité du processus de production – matières et produits finis ? Les comptes sur les catégories de produits et sur les emplacements spéciaux (production, pertes d'inventaire) ne suffisent apparemment pas.

Réponse:

En bref, le chemin pour que fabrication et comptabilité concordent :

  • Catégories de produits : activer la valorisation Automatisée (permanente) et définir les comptes – stock, entrée, sortie.
  • Emplacement virtuel « Production » : lui donner ses propres comptes de valorisation, pour que la consommation de matières et la production de produits finis passent par un compte d'en-cours (WIP).
  • Postes de travail : indiquer le coût horaire et ajouter des opérations aux nomenclatures (BoM) – le coût de revient inclut alors la main-d'œuvre, pas seulement les matières.
  • Fin de mois : si un ordre de fabrication est encore ouvert, à partir d'Odoo 17 il peut être comptabilisé en en-cours via l'action WIP accounting.
  • Contrôle de gestion : un compte analytique par ordre de fabrication.

# Rapport « Marge produit » : marge attendue erronée pour les variantes

Sales Reporting · répondu le 19.11.2026

Question: Pour « Expected Margin », le rapport prend le prix du modèle de produit (1 $), pas celui de la variante (1 $ + supplément de variante 267,78 $). Sales Gap et Expected Margin sont donc faux. Peut-on corriger cela ?

Réponse:

Ce n'est pas une erreur de configuration – le rapport est construit ainsi. Dans le code source (product_margin, Odoo 18), le « chiffre d'affaires attendu » est calculé comme quantité × list_price du modèle de produit. Les suppléments de variante (price_extra) ne sont pas pris en compte – d'où 32 × 1 $.

  • Solution simple : tenir le vrai prix de base sur le modèle au lieu de 1 $.
  • Sinon, un petit module qui remplace dans cette requête le list_price du modèle par le prix de la variante (lst_price).

# Odoo 19 sur Odoo.sh : analyser les e-mails des transporteurs par IA et mettre à jour le suivi des commandes fournisseurs ?

Purchase Inventory AI · répondu le 19.11.2026

Question: Nous utilisons Odoo 19 Enterprise sur Odoo.sh. Quels modules OCA d'intégration transporteur / suivi faut-il regarder ?

Réponse:

Les réceptions n'ont pas de champ prêt à l'emploi « numéro de suivi de l'achat ». Il est plus pratique d'écrire le numéro dans carrier_tracking_ref de la réception (stock.picking) – ce champ vient avec le module delivery.

  • Un alias e-mail dédié aux e-mails des transporteurs.
  • Une règle d'automatisation sur les e-mails entrants.
  • Un appel à l'IA qui extrait le numéro de commande et le numéro de suivi du texte.
  • L'écriture dans la réception et un message dans le chatter de la commande.

L'OCA a des modules transporteurs prêts dans le dépôt delivery-carrier, mais ils sont surtout conçus pour les expéditions sortantes.

# Prévision de trésorerie pour une société de conseil IT : facturation horaire plus abonnements

Accounting Services · répondu le 19.11.2026

Question: 75 % des prestations sont facturées à l'heure, 25 % en montants mensuels fixes (abonnement), Odoo 19. Recherché : une prévision de trésorerie avec montants planifiés, saisis, facturés et payés – chaque montant une seule fois –, TVA à part, coûts de personnel issus du plan de paiements.

Réponse:

Une base prête est le module OCA mis_builder_cash_flow (dépôt account-financial-reporting). Il construit une prévision à partir des créances et des dettes par date d'échéance et permet d'ajouter des lignes planifiées : salaires, leasing, frais fixes.

  • Abonnements : selon les dates des prochaines factures.
  • Feuilles de temps : heures pas encore facturées (champ qty_to_invoice des lignes de commande).
  • Factures : selon la date d'échéance.

La règle « chaque montant une seule fois » (plan → feuille de temps → facture → paiement) est à ajouter soi-même – une petite extension.
