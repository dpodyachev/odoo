🔒 Защищённая страница – как это работает

✅ Вход выполнен. Эту страницу видят только те, кто знает логин и пароль.

Как это сделано

  1. Сайт статический и размещён на Cloudflare Pages, своего веб-сервера с nginx нет.
  2. Для адресов под /test/ перед отдачей страницы на Cloudflare выполняется небольшая функция (Pages Functions, файл functions/test/_middleware.js).
  3. Она читает заголовок Authorization, сравнивает логин и пароль с секретом TEST_AUTH (за постоянное время, без утечки через тайминг) и только тогда отдаёт страницу. Иначе отвечает 401 с WWW-Authenticate, и браузер показывает своё окно входа.
  4. Логина и пароля нет ни в HTML, ни в (публичном) Git-репозитории: они хранятся как зашифрованный секрет в настройках проекта Cloudflare.
  5. _routes.json ограничивает функцию путём /test/*, остальной сайт остаётся полностью статическим и быстрым.
  6. Если секрета нет, страница остаётся закрытой (fail closed).
