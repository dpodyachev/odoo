🔒 Protected area – how it works

✅ Login successful. Only visitors with the user name and password can see this page.

How it is done

  1. This website is static and hosted on Cloudflare Pages – there is no own web server with nginx.
  2. For addresses under /test/, a small function runs at Cloudflare before anything is served (Pages Functions, file functions/test/_middleware.js).
  3. It reads the Authorization header, compares user name and password in constant time with the secret TEST_AUTH, and only then serves the page – otherwise it answers 401 with WWW-Authenticate, and the browser shows its login box.
  4. User name and password are not in the HTML and not in the (public) Git repository, but stored as an encrypted secret in the Cloudflare project settings.
  5. _routes.json makes sure the function only runs for /test/* – the rest of the website stays purely static and fast.
  6. If the secret is missing, the page stays locked (fail closed).
